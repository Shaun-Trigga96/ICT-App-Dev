From your Big_O.docx — Key complexity comparison
// ─── ITERATIVE FACTORIAL ─── Time O(n) · Space O(1)
public static int factorial(int n) {
  int prod = 1;
  for (int i = 1; i <= n; i++) { // n iterations
    prod *= i;
  }
  return prod;
}

// ─── RECURSIVE FACTORIAL ─── Time O(n) · Space O(n) ← stack frames!
public static int fact(int n) {
  if (n == 0) return 1; // base case
  else return n * fact(n - 1); // recursive case — n calls on stack
}

// ─── RECURSIVE FIBONACCI ─── Time O(2ⁿ) · duplicated calls!
public static int fib(int n) {
  if (n == 0 || n == 1) return 1;
  else return fib(n - 1) + fib(n - 2); // branches double each level
}
03

Bubble Sort & Case Analysis

SO4

Your bubbleSort() in Big_O.docx has the comment showing steps as (n-1)(n-1) = n²-2n+1, simplifying to O(n²). You need to know all three cases: Best case (already sorted) = O(n) with optimised version, Worst case (reverse sorted) = O(n²), Average case = O(n²). Also refer to your Bubble_Sort_and_Matrix_Multiplication.pptx.

05

Doubly & Circular Linked Lists

SO6

Singly linked lists can't traverse backwards — expensive for deletion of a known node. Doubly linked lists add a prev pointer to solve this. Circular linked lists connect the tail back to head — useful for round-robin scheduling. Know the trade-offs of each in terms of memory (extra pointer) and operation efficiency.

Your T1 test is written. Practice tracing bubble sort, drawing linked list nodes, and writing Big O analysis on paper under time pressure.

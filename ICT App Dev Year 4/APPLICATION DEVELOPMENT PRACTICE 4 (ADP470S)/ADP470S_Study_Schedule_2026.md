## Study Tips & Best Practices

### Daily Study Routine
1. **Morning (1 hour):**
   - Review previous day's concepts
   - Read theory from textbook
   
2. **Afternoon (2 hours):**
   - Implement algorithms
   - Code practice
   
3. **Evening (1 hour):**
   - Solve problems
   - Participate in forums/discussions

### Weekly Goals
- Complete all assigned readings
- Implement all algorithms in Java
- Solve minimum problem counts
- Attend all classes
- Participate in study groups

### Code Practice Guidelines
1. **Understand First:** Don't just copy code
2. **Implement from Scratch:** Type out algorithms yourself
3. **Test Thoroughly:** Use multiple test cases
4. **Analyze Complexity:** Always determine Big O
5. **Document Code:** Write clear comments
6. **Review Regularly:** Revisit old implementations

### Using Karumanchi's Textbook Effectively
1. **Read actively:** Make notes, highlight key points
2. **Do all examples:** Work through each example problem
3. **Solve exercise problems:** Attempt before checking solutions
4. **Use diagrams:** Draw data structure diagrams
5. **Code alongside:** Implement concepts as you read

### Resources Beyond Textbook
- **VisuAlgo.net:** Algorithm visualizations
- **GeeksforGeeks:** Additional problems and explanations
- **LeetCode:** Practice problems (Easy to Medium)
- **YouTube:** Algorithm explanation videos
- **CourseMonk:** Karumanchi's own platform

### Time Management
- **Use Pomodoro Technique:** 25 minutes study, 5 minutes break
- **Avoid procrastination:** Start assignments early
- **Weekly planning:** Plan week ahead every Sunday
- **Track progress:** Use the bash script to track completion

### Group Study Tips
- Meet weekly with peers
- Explain concepts to each other
- Share implementations (for learning, not copying)
- Discuss problem-solving strategies
- Form WhatsApp/Discord study groups

### Exam Preparation Strategy
1. **Start early:** Don't cram
2. **Practice writing:** Code on paper without IDE
3. **Time yourself:** Practice under exam conditions
4. **Review mistakes:** Learn from errors
5. **Stay healthy:** Sleep well, eat properly

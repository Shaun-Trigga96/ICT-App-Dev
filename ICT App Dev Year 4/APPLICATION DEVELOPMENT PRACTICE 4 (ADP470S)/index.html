ADP470S · User Guide

How to use the
Learning System Script

A complete navigation guide — from launching the script to completing quizzes and tracking your progress across all 4 terms.

Part 1

Launching the Script

1

Open a Terminal

On Linux/Mac: open your Terminal app. On Windows: open Git Bash (not PowerShell or CMD — the script won't work there).

2

Navigate to the script's folder

Use cd to go to the folder where you saved adp470s_learning_system.sh. For example, if it's on your Desktop:

$ cd ~/Desktop
3

Make the script executable (first time only)

You only need to do this once — it gives the script permission to run.

$ chmod +x adp470s_learning_system.sh
4

Run the script

Type the command below and press Enter. You should see the main menu appear.

$ ./adp470s_learning_system.sh
Initializing ADP470S Learning System...
Ready!
Part 2

The Main Menu

After launching, you will see the main menu. It shows all 4 terms with a live progress bar for each. Type a number and press Enter to select.

Main Menu Choices

What each number does

1

Term 1 — Algorithms & Complexity (10% weight). Opens the Term 1 sub-menu with 7 weekly topics + a practice test.

2

Term 2 — Stacks, Queues, Trees & Sorting (35% weight). Opens 13 weekly topics + a practice test.

3

Term 3 — Graphs & Hashing (20% + Project). Opens 8 weekly topics, a project entry, and a practice test.

4

Term 4 — Advanced Topics & Review (35% weight). Opens 6 weekly topics + the final test.

5

View All Progress & Scores — Shows a full overview of every term's completion bar and your most recent quiz scores.

6

Reset All Progress — Wipes your saved progress and quiz scores. You'll be asked to confirm by typing yes.

0

Exit — Closes the script.

Part 3

Navigating Inside a Term

Once you enter a term, you see a checklist of all its weeks. Here's how each action works:

A

Mark a week as complete / incomplete

Type the week number (e.g. 2) and press Enter. It will toggle between ✓ Complete and [ ] Incomplete. The progress bar at the top updates instantly.

Choice: 2
Marked as complete!
B

Take a quiz on a specific week

In Term 1, type 9 for the quiz option. You'll then be asked which week number you want to quiz on (1–7).

Choice: 9
Enter week number (1-7) for quiz: 2
═══ Term 1 Week 2 Quiz ═══

Term 2 uses 15, Term 3 uses 11, Term 4 uses 8 for their quiz options.

C

Take the practice exam / test

Each term has one exam entry at the bottom of its list. In Term 1 it's option 8. In Term 2 it's 14. Term 3 is 10. Term 4 is 7. The exam is automatically saved when you finish it.

Choice: 8
═══ TERM 1 PRACTICE EXAM (10% Weight) ═══
Ready to start? (y/n): y
D

Go back to the Main Menu

Type 0 and press Enter from any term sub-menu to return to the main screen.

Choice: 0
← Returns to main menu
Part 4

Answering Quiz Questions

1

Each question shows 3 options

Read the question, then type 1, 2, or 3 and press Enter.

Q1: Recursion requires:
1) A base case
2) Loops
3) Arrays
Answer (1-3): 1
Correct!
2

Your score is shown at the end

After all 5 questions (or 10 for the exam), you see your score, percentage, and it's automatically saved to your history.

═══════════════════════════

═══════════════════════════
3

Press Enter to continue

After the score is shown, just press Enter (no number needed) to go back to the term menu.

Tips & Troubleshooting

Good to Know

✓ Only type numbers

All menus only accept numbers. Typing letters or leaving the answer blank and pressing Enter will show an error message — just try again.

✓ Your progress is saved automatically

A hidden file called .adp470s_progress.json is created in the same folder as the script. Don't delete it or you'll lose your progress.

⚠ Reset is permanent

Main Menu option 6 deletes all your progress and quiz scores. You must type the full word yes to confirm — y alone won't work.

⚠ Python 3 must be installed

The script uses Python 3 to save and read progress. If you see errors about python3, install it from python.org first.

✓ Toggling works both ways

Selecting a week number that's already marked complete will unmark it. Useful if you accidentally checked off the wrong week.

✓ Quiz scores are cumulative

Every quiz attempt is stored with a timestamp. The "View All Progress" screen shows your most recent score for each topic.

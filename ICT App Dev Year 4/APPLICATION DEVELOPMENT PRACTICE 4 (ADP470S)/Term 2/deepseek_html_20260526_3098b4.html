QUESTION 1 [20 MARKS]

Factorial Implementation & Performance Comparison
The factorial of a non-negative integer n is defined as: \[ n! = \begin{cases} 1 & \text{if } n = 0 \text{ or } n = 1\\ n \times (n-1)! & \text{if } n \ge 2 \end{cases} \]

1.1 Using a trace, explain how the recursive factorial method works. Demonstrate with n = 5, showing each recursive call and return.[8]
💡 Hint: Show call stack & unwind – e.g., factorial(5) → 5 * factorial(4) → ... until base case.
1.2 Using a trace, explain how the iterative factorial method works. Provide step-by-step execution for n = 5 using a loop.[6]
1.3 Using Big-O notation, compare the performance of recursive vs iterative factorial from the perspectives of time complexity and space complexity. Explain which approach is generally preferable in real-world applications and why.[6]

QUESTION 3 [35 MARKS]

Sorting Algorithms – Principles, Traces & Complexity

3.1 QuickSort (Working + Example)
Explain the working principle of the QuickSort algorithm. Demonstrate how it sorts the array:
{90, 23, 5, 109, 12}
Show at least the first partition step (choose pivot as last element) and recursive calls to illustrate the mechanism. Then, state the best, average, and worst-case time complexities using asymptotic notation.[12]
3.2 HeapSort (Working + Example)
Describe the strategy behind HeapSort (using a max‑heap). Transform the same array {90, 23, 5, 109, 12} into a max‑heap (show heapify steps) and then illustrate how the sorted order is achieved by repeatedly extracting the maximum. Include the final time complexity (worst & average) in Big‑O notation.[15]
3.3 Bubble Sort (Complexity & brief trace)
Show how Bubble Sort modifies the array {90, 23, 5, 109, 12} during the first two passes (enough to demonstrate understanding). Provide the Big‑O expression for Bubble Sort’s worst‑case and best‑case performance.[8]

## Term 1 — Foundations, Recursion, Searching, Sorting, Arrays & Linked Lists

1. "Explain algorithmic complexity (Big-O, Big-Theta, Big-Omega) using simple analogies, then give 3 practice problems with worked solutions."
2. "Compare recursion vs iteration using Factorial and Fibonacci as examples. Show the recursion tree for Fibonacci(5) and explain why it's inefficient."
3. "Walk me through Linear Search and Binary Search step by step on a sample array. Compare their time complexity and explain when each is appropriate."
4. "Explain Bubble Sort with a step-by-step trace on the array [5, 2, 9, 1, 5, 6]. Derive the best-case, worst-case, and average-case time complexity."
5. "Explain 2D and multidimensional arrays with a real-world example (e.g. a grid or matrix), including how memory is laid out."
6. "What are the limitations of arrays that motivate the use of Linked Lists? Explain Singly Linked List operations (insert, delete, traverse) with diagrams described in words."
7. "Compare Singly, Doubly, and Circular Linked Lists. What problem does each solve that the previous one didn't?"
8. "Generate 10 short-answer practice questions covering Term 1 (complexity, recursion, searching, bubble sort, arrays, linked lists) with model answers, similar in style to a first written test worth 10%."

## Term 2 — Stacks, Queues, Trees, and Sorting Algorithms

1. "Explain the Stack data structure (LIFO), its core operations (push, pop, peek), and how recursion uses a call stack internally."
2. "Explain Queue operations (FIFO) and then Circular Queue — why is a circular queue needed instead of a simple queue?"
3. "What is a Priority Queue and how does it differ from a normal queue? Give a real-world use case and a simple implementation approach."
4. "Explain Binary Trees and tree traversals (in-order, pre-order, post-order, level-order) with a worked example tree and the traversal outputs."
5. "Introduce AVL Trees / height-balanced binary trees. Why do we need self-balancing trees, and what are left/right rotations?"
6. "Compare and explain these sorting algorithms: Selection Sort, Insertion Sort, Merge Sort, Quick Sort, and Heap Sort. For each, give time/space complexity and a step-by-step trace on a small array."
7. "Create a comparison table of all sorting algorithms covered (bubble, selection, insertion, merge, quick, heap) by best/worst/average case complexity, stability, and in-place status."
8. "Quiz me with 15 mixed questions on stacks, queues, trees, and sorting algorithms, matching the style of a written test."

## Term 3 — Graphs, Traversal, Shortest Path, and Hashing

1. "Explain how graphs are represented in a computer (adjacency matrix vs adjacency list) with pros/cons of each."
2. "Explain graph traversal algorithms: Breadth-First Search (BFS) and Depth-First Search (DFS). Trace both on a sample graph and show the order of visited nodes."
3. "Explain Prim's and Kruskal's algorithms for Minimum Spanning Trees with a worked example on the same small graph, comparing their approach."
4. "Explain Dijkstra's algorithm for shortest path with a full step-by-step trace, including the distance table at each iteration."
5. "Explain the Floyd-Warshall algorithm and Disjoint Set (Union-Find) data structure — what problems do they solve and how do they differ from Dijkstra/Kruskal?"
6. "Explain Hashing: hash functions, collision handling (chaining vs open addressing), and load factor. Give a worked example inserting 6 keys into a small hash table."
7. "Create a decision guide: given a graph problem description, which algorithm (BFS/DFS/Dijkstra/Prim/Kruskal/Floyd-Warshall) should I use and why?"
8. "Generate a practice project brief similar to a Term 3 individual project involving graph traversal or shortest-path algorithms, with a marking rubric."
